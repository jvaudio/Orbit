# Orbit 0.1.1

Orbit now includes automatic updates through Sparkle.

- **Check for Updates…** is available in the menu bar menu, application menu, and Settings.
- Orbit checks for updates daily by default. Settings lets you disable scheduled checks or opt into automatic downloads and installation when Orbit quits.
- Updates and the feed are cryptographically signed with Orbit’s dedicated update-signing key. The updater verifies the archive before extraction; public apps remain Developer ID signed and Apple notarized.
- Update installation preserves enabled utilities, settings, and launch-at-login registration.
- Development Run builds do not schedule updates or replace themselves with public releases.

## Install

Download **Orbit-0.1.1-macOS-universal.zip**, unzip it, and drag **Orbit.app** into **Applications**, replacing the previous copy. Open Orbit from Applications.

**If you have Orbit 0.1.0, install this version manually once.** Version 0.1.0 has no updater. After installing 0.1.1, future versions can be installed directly through Orbit.

Requires macOS 14 or later on Apple silicon or Intel. Physical Intel and macOS 14 verification remain outstanding.

## Verification

All 72 automated tests pass. The update was exercised end to end from a private older baseline using a signed localhost feed: download, verification, installation, and relaunch into the exact notarized 0.1.1 binary in Applications. Existing Orbit preferences and launch at login were preserved. The installed app uses the production HTTPS feed, with no localhost exception. Tampered feed and archive bytes were rejected. The baseline was a test fixture with the new updater; it does not change the one-time manual install requirement for the original public 0.1.0.
