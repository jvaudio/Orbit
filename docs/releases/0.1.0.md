# Orbit 0.1.0

Orbit’s first public release brings two independently enabled utilities to a native macOS menu bar app.

- **Find My Mouse:** shake your pointer to spotlight it and dim connected displays. Adjust sensitivity, radius, and dimming, or preview the effect.
- **Right-Click Menu:** instant Cut, Copy, Paste, Rename, Share, and Delete tiles, plus native color tags, in supported Finder file views. Cut/Copy/Paste also work in supported focused text controls. Unavailable actions stay visible and disabled. Use **Show macOS Menu** for app-specific commands.
- Native appearance, an optional launch-at-login setting, and local preferences. Both utilities start off on a fresh installation.

## Download and install

1. Download **Orbit-0.1.0-macOS-universal.zip** from the assets below.
2. Unzip it and drag **Orbit.app** into **Applications**.
3. Open Orbit from Applications. Its icon appears in the menu bar; use it to reopen the utilities window.
4. Enable the utilities you want. For Right-Click Menu, allow Orbit in **System Settings → Privacy & Security → Accessibility**, then click **Check Access** in Orbit.

Requires **macOS 14 or later**. The app is universal for **Apple silicon and Intel Macs**, Developer ID signed, and notarized by Apple. The ZIP contains the app with its notarization ticket stapled. `SHA256SUMS.txt` contains the archive checksum.

## Validation and limitations

All 67 automated tests pass. Live Finder Copy/Paste, Cut/move-Paste, Rename, Share chooser, Delete-to-Trash, color tags, and native fallback were checked. TextEdit Copy/Cut/Paste was checked. Share testing opened and cancelled the chooser without sending a file. The optimized release app was launch-checked on Apple silicon with macOS 27.2; physical Intel and macOS 14 testing remain outstanding.

Right-Click Menu applies only where Orbit can identify an unambiguous file or supported text context. Other contexts retain their native menu. Advanced and third-party commands are available through **Show macOS Menu**. Automatic updates are not included in this release; install future versions from GitHub Releases. Finder background resolution currently uses the path bar when Finder omits its folder URL; unsupported or ambiguous views fall back to the native menu.

Apple’s cursor enlargement preference remains unchanged. No keyboard monitoring or screen-recording permission is used.
